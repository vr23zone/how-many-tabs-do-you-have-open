My answer to the make.fun bounty
[How Many Tabs Do You Have Open?](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d)
is **365** — one tab for every day of the year. Each day gets exactly one tab,
opened in the morning and (in theory) closed by nightfall; in practice they
accumulate at the same rate the year does.

Running `main.ts` (Node 22) writes the bare number `365` — exactly 3 bytes,
no trailing newline, nothing else — to `/output/entry.txt`.
